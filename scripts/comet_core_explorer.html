How to read the comparison

Positive / warm. Higher mean detected PLA count per spatial bin in Running. Negative / cool. Lower mean count in Running. White is zero difference; grey means insufficient valid tissue coverage.

How to read section coverage

N is a tissue-section count. It is not the number of PLA detections, occupied object bins or independently replicated animals.

Valid zero. A bin fully inside a section mask contributes even when its PLA count is zero. Any partly outside bin is excluded from that section's denominator.

Missing comparison. A difference can be shown only when both condition-specific section counts are at least one.

What the coverage supports

Evidence. The maps disclose the actual contributing-section count behind each mean, including variation caused by mask boundaries.

Limit. These maps cannot be replaced by detection footprints. Without existing tissue masks, the tissue-valid denominator is unknown.
