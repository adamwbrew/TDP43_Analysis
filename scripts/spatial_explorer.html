How to read the evidence

Question. Which native locations contain more detected objects, and do PLA and ChAT occupy similar regions?

Evidence. Count maps use all rows of the selected export, one midpoint per row, with no smoothing. Overlay dots are a display sample; their density is not the count estimator.

Limits and next useful check

Limits. Raw count per full square is not density per measured tissue area. Empty locations may be missing tissue, an analysis boundary or a real absence of detections. Blended colour does not define colocalization. Native Y increases downward as a display convention; calibration and anatomical orientation remain unverified.

Next. Use the selected coordinate window to review original fluorescence channels, detection settings and ROI boundaries. Confirm the sample mapping and tissue masks before group-level anatomical comparisons.

Selected export provenance

Measurement definitions

  • Position: x = (XMin + XMax)/2; y = (YMin + YMax)/2. Bounding-box midpoints are reconstructed proxies, not exported centroids or original microscopy pixels.
  • Counts: one valid source row per object-class bin; fixed widths of 64, 128 or 256 native units on a zero-anchored grid. No interpolation, smoothing or estimated tissue mask.
  • Association: 100 × PLA rows with literal ChAT-presence value 1 / all PLA rows in the same bin. The minimum-PLA control hides low-denominator bins only for percentages.
  • Scale: the same class, bin width and colour transform use identical colour limits across every export. Count colour can be linear or log(1 + n); hover always reports raw counts.
  • Coverage: zero means no exported detections in the bin. Without tissue masks, zero is not a validated tissue-negative observation. Blank percentage bins fail denominator support.
  • Display points: deterministic capped samples of source objects preserve IDs and exact native bounding boxes. All eligible rows feed the count grids.

Required inputs and decisions

1
Authoritative sample and repeat-export mapping

Map each export to physical section, animal, condition and PLA arm; identify alternative ROI analyses and primary inclusion decisions. Historical labels are retained as observations.

2
Existing accepted alignment

Provide approved transforms, reference frame and the accepted alignment-check figure. Native coordinates remain preserved. Computational proposals do not constitute anatomical approval.

3
Aligned tissue masks and centroid definition

Supply validated masks in the same coordinate system, true object centroids or an explicitly approved proxy, units and grid origin/bin width. No object-detection envelope substitutes for a tissue mask.

4
Biological aggregation rule

Confirm how multiple sections relate to animals and the intended independent experimental unit. Report contributing-section/animal counts and missing coverage alongside every contrast.

What the finished maps will calculate

Separate PLA arms. TDP43–HK1 and TDP43–PFKP maps remain distinct after assignments are confirmed.

Raw object count per accepted bin. Count each accepted centroid once. Preserve valid tissue bins with no PLA as zero. Exclude a section-bin that is not fully inside its tissue mask.

Condition summaries and coverage. Use the requested section-level mean count and Running − Homecage difference on one common approved grid, while respecting the animal-level dependence in inference.

Visible uncertainty. Include per-condition contributing-section coverage and a clear missing-data display. Do not substitute a visually smooth surface for absent measurements.
